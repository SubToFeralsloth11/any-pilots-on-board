# Any Pilots On Board?

A chaotic co-op multiplayer 3D game made with Godot 4.7.

## Builds

GitHub Actions (`.github/workflows/build.yml`) runs the unit tests and exports Windows, macOS and Linux builds on every push; the zips are downloadable from the run's artifacts. Publishing a GitHub release attaches the three zips to it.

The macOS build is unsigned: right-click the app and choose Open the first time.
